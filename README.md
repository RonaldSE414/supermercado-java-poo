# 🛒 Sistema de Supermercado em Java

Projeto simples em Java utilizando Programação Orientada a Objetos (POO) para simular um sistema de produtos.

## 📌 Conceitos utilizados
- Herança
- `@Override`
- Uso de `super`
- Controle de estoque

## ⚙️ Funcionalidade

O sistema permite:
- Criar produtos
- Adicionar estoque
- Realizar vendas
- Trabalhar com produtos perecíveis
